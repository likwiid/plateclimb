# Architecture

PlateClimb is an Expo (SDK 54) React Native app for Android and iOS, written in
strict TypeScript. It ships one program, Foundational Fitness (12 weeks), and
is fully offline: the program, workouts and history live in SQLite on the
device. There is no account, no server, no sync, no backup and no AI
service. The only network use is downloading exercise photos from
free-exercise-db.

## Stack

| Concern | Choice |
|---|---|
| App framework | Expo SDK 54, React Native 0.81, expo-router 6 |
| Styling | NativeWind (Tailwind classes), dark theme only |
| State | Zustand; preferences persisted to AsyncStorage |
| Data | SQLite through expo-sqlite, with FTS5 for exercise search |
| Animation | react-native-reanimated |
| Notifications | Notifee for the rest timer |
| Tests | Jest with ts-jest (node environment) |
| Lint | ESLint 9 with eslint-config-expo |

## Module map

```
src/
  data/                    bundled content: the program, exercise catalog, photo lookup
    program/               foundationalFitness.json and its types
  features/
    program/               Program tab, week screen
    workout/               day screen, session flow, set logging, rest timer, summary
    exercise/              exercise detail
    settings/              settings sections (units, feedback, week, reset)

```

Path aliases: `@features/*`, `@shared/*` and `@data/*` (see `tsconfig.json`).

## Data model

The schema is created in one step by `src/shared/db/migrate.ts` (schema
version 1). Two groups of tables:

- **Program:** `program_weeks` (week number, block, week off flag),
  `program_days` (day name, type, focus text and a session key such as `legs`
  or `long_cardio`), `program_exercises` (one row per exercise slot: sets,
  rep range, RPE targets, rest, unit, prescribed weight in kg, superset group,
  slot key and note) and `exercise_substitutions` (alternatives per slot, in
  order).
- **Catalog and history:** `exercises` (free-exercise-db plus the program's
  own exercises with their video links), `workout_sessions`, `workout_sets`
  and `exercise_last_performed`.

## Program data and seeding

`src/data/program/foundationalFitness.json` holds the whole program: 12
weeks, 84 days, 286 exercise slots with two substitutions each, and the 79
exercises they use. Cardio, rest and week off days carry focus text and no
slots.

On launch, `seedDatabase` (`src/shared/db/seed.ts`) checks for an empty
catalog or program. On a fresh install it seeds the free-exercise-db catalog,
then `seedProgram` (`src/data/seedProgram.ts`) upserts the program's
exercises by name (an existing catalog entry only gets its video link) and
writes the weeks, days, slots and substitutions in one transaction. **Reset
All Data** deletes the database file and runs the same path, so the program
comes back fresh.

The JSON is generated by `scripts/build-program-data.mjs` from an export of
the five program tables, passed as an argument (there is no default path).
The script reads only those tables, replaces each slot note with reviewed
public wording, and refuses to write output that contains em or en dashes or
personal phrasing.

## Weights

```
start workout
  -> workoutSessionLoader.loadSessionData    (sets from the program)
  -> useWorkoutPrefill
       1. prescribedWeights                   (program start weight, kg to lb if needed)
       2. getLastPerformedBatch               (what you lifted last time, wins)
  -> prefillWeights.applyWeightsToExercises   (pure, warm-up ramp too)
```

There is no automatic progression: a weight only changes when you change it.
A swapped exercise has no prescribed weight, so it starts from its own
history. Bodyweight slots have none either.

## Network use

| What | Where | When |
|---|---|---|
| Exercise photos | `raw.githubusercontent.com/yuhonas/free-exercise-db` | Opening an exercise; a bundled placeholder shows when offline |
| Form videos | YouTube, through the system | Tapping **Watch a form video**; the app hands the link to the phone |

The image download is the only request the app makes itself. Seeding is fully
offline from `src/data/`, notifications are local, and nothing is uploaded
anywhere.

## Conventions

- New source files start with `// SPDX-License-Identifier: GPL-3.0-or-later`.
- Pure logic (program data checks, weight pre-fill, labels, photo lookup)
  stays free of React Native imports so Jest can test it directly.
- User-visible text uses plain hyphens, not em or en dashes.
